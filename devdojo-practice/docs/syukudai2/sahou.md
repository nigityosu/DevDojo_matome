## 各言語の書き方の作法
### html,css,javascriptの作法
- html: htmlの基本的な書き方を覚えましょう。
    - htmlはwebサイトの土台を作る言語です。なのでここに書くのは文字と画像のみです。
    - htmlを書くときにはheadとbodyに分けて書き,headにはタイトルやcss,javascriptの読み込み,基本的な情報などを書きます。bodyにはheader,main,footerなどに分けて書きます。
    - 文字を書くときはp,a,h1~6,divなどのタグを使います。
        - <"pなど">ここに文字を書く</"pなど">このように書きます。
    - 画像を書くときはimgタグを使います。
        - <"img src="画像のURL">このように書きます。
    - 文字や画像を書くときにはクラスを作ることをおすすめします。こうすることでcssで操作するときにそのクラス名を指定することでその要素を操作することができます。
        - <"div class="クラス名"">ここに文字や画像を書く</"div">このように書きます。
    - javascriptで操りたいときはidをつけることをおすすめします。こうすることでjavascriptで操作するときにそのid名を指定することでその要素を操作することができます。
        - <"div id="id名"">ここに文字や画像を書く</"div">このように書きます。
    - クラスやidの名前を作るときは英語でわかりやすい名前をつけることをおすすめします。なぜなら日本語で書くと正常に動かなくなる可能性があり、また後でcssやjavascriptで操作するときに書きずらくなってしまったりするからです。
    - またクラス名やid名は他の要素と被らないように注意しましょう。被ってしまうと同時に動いてしまい、意図しない動きをしてしまう可能性があります。

- css: cssの基本的な書き方を覚えましょう。
    - cssはwebサイトの見た目を作る言語です。なのでここに書くのは色や大きさ、配置などです。
    - cssを書くときにはセレクタとプロパティに分けて書きます。セレクタはどの要素を操作するかを指定し、プロパティはその要素のどの部分を操作するかを指定します。
    - セレクタにはタグ名、クラス名、id名などがあります。
        - タグ名: p,div,h1など
        - クラス名: .クラス名
        - id名: #id名
    - プロパティには色や大きさ、配置などがあります。
        - 例: color, font-size, margin, padding, displayなど
    - 具体的な書き方は以下の通りです。
        - セレクタ {
            プロパティ: 値;
          }
    - 例:
        - .example {
            color: red;
            font-size: 20px;
            margin: 10px;
          }
    - またcssで書いた名前が違うと正常に動かなくなってしまうので注意しましょう。
